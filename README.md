# ポポさんぽ

ポポと一緒におさんぽ。歩いた分だけポイントが貯まるアプリ（PWA）です。

- 1歩 = 1ポイント。1日の目標を達成するとボーナス +500pt。
- ポポの表情が、さんぽ中・達成時で切り替わります。
- データはスマホの中だけに保存されます。登録不要。

## 使い方

1. `https://193murano-cmyk.github.io/popo-sanpo/` をスマホで開く。
2. 共有メニューから「ホーム画面に追加」。
3. 「さんぽスタート」を押して歩く。iPhone はセンサーの許可を「許可」にする。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面・動き・保存（1ファイル完結） |
| `manifest.json` | ホーム画面用の名前とアイコン |
| `sw.js` | オフラインで開けるようにする |
| `img/` | ポポの画像とアイコン |
| `docs/spec.md` | 仕様書 |
| `docs/plan.md` | 構成案・ロードマップ |

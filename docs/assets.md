# 画像アセット一覧（フェルト版）

ポポさんぽに必要な画像のリスト。Gemini（ナノバナナ）で手動生成・選定し、`img/raw/` に置く。
背景の透明化・縮小・リネームはアプリ側（ロビン）が行うので、**生成した画像をそのまま置けばよい**。

- 版：v0.2（2026-09-09）
- 画風：フェルト版（ニードルフェルト／ぬいぐるみ調の立体）。参照画像は各キャラの「フェルト_立ち絵_確定_2026-08-10.jpg」
- 置き場所：`img/raw/<ファイル名>`（jpg / png どちらでも可）
- 差し替え後の本番ファイル：`img/<同名>.png`（透明背景・長辺 720px）

---

## 生成の共通条件（全画像）

| 項目 | 指定 |
|---|---|
| 背景 | **真っ白（#FFFFFF）**。空・地面・小物・文字・枠を入れない |
| 構図 | **全身**。頭からつま先まで切れない。足元とまわりに1割ほど余白 |
| 影 | 足元の小さな接地影だけ、または無し。体から離れた影・壁の影は無し |
| 向き | 正面〜やや斜め（右向き）。真横・後ろ姿は不可 |
| 光 | 確定版と同じ（やや左上から）。全画像で揃える |
| サイズ | 正方形 1024×1024 以上、または縦長（例 1024×1536）。横長は不可 |
| 1枚1体 | 他のキャラや小物を一緒に入れない |
| 手 | 日常カットなので赤いフェルトの手。綿毛の手は「飛ぶ」ときだけ |

プロンプト末尾に足す一文（そのままコピー）：

```
plain pure white background, no scenery, no props, no text, full body visible with small margin around, only a soft small contact shadow under the feet, same lighting as the reference
```

## 受け渡しの流れ

1. Gemini で生成 → 良いものを選ぶ
2. ファイル名を上の表のとおりにして `img/raw/` に置く（拡張子は jpg / png どちらでも）
3. `main` に push（ターミナルのロビンに頼むか、GitHub の「ファイルをアップロード」でも可）
4. アプリ側のロビンに「raw に入れた」と伝える → 透明化・縮小・差し替え・プレビュー更新

## 差し替え時のチェック（アプリ側）

- 白背景を透明化したとき、綿毛の白い部分が抜けていないか
- 5枚のポポの大きさ・足の位置がそろっているか（そろっていないと切り替えで跳ねて見える）
- 空色の背景に載せたとき、フェルトの質感が浮いていないか。必要なら背景を紙の質感に寄せる

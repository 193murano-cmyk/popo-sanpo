# 「ポポさんぽ」はエンターテインメント散歩アプリになれるか

企画責任者としての判断と提案。2026-09-09。
根拠：キャラクター設定資料集（全10体）、共通ビジュアル規定、pointpay キャラクター設定書、案件メモ、現行アプリ v0.1。

---

## 0. 結論を先に

**なれる。ただし「歩数計にポポを貼ったアプリ」では絶対に勝てない。**

勝ち筋はひとつ。**「歩くと、物語が進む」**。
『五円玉のポポ』の世界観をそのまま機能に翻訳し、歩数を「風」に、達成を「風がとおる」に、物語を「風がとおると開く」ものにする。歩数アプリを作るのではなく、**歩くことでしか読めない絵本**を作る。

これができれば、他社が真似できない理由が3つ揃う。

1. **自社IPを10体持っている**（歩数アプリ各社はキャラを借りるか、無い）
2. **リアルの加盟店がある**（pointpay の店舗網＝物語の「町」を現実に持てる）
3. **縦型絵本アニメがすでに制作ラインに乗っている**（コンテンツ供給の目処がある）

## 1. 市場の現実

歩数×報酬アプリはすでに飽和している。トリマ、Miles、aruku&、dヘルスケア、Coke ON、楽天ヘルスケア。共通の構造は「歩く → 小額ポイント → 単価が安くて飽きる → 離脱」。**ポイントで継続率は買えない**。これが業界の10年分の結論。

一方で継続率が桁違いなのは Pokémon GO、ピクミンブルーム、Pokémon Sleep。共通点は「歩くと、何かが育つ／積み上がる／物語が進む」。**報酬ではなく意味が続けさせる**。

ポポさんぽが戦うべきはこちらの土俵。ただし任天堂・Niantic 級のIPはない。だから**「IPの知名度」ではなく「IPの構造」で勝つ**。ポポの世界観は、偶然にも歩行体験と構造が一致している。

## 2. コアアイデア：歩く → 風がとおる → 物語が開く

世界観の核は「五円玉の穴＝ご縁の風のとおり道」。これを機能にそのまま翻訳する。

| 世界観 | アプリの機能 |
|---|---|
| 風 | 歩数。歩くほど風が溜まる |
| 風がとおる | 1日の目標達成 |
| 風のとおり道がつながる | 連続達成（ストリーク） |
| かざあな町 | ホーム画面。住人が増えていく |
| 穴あき硬貨 | ポイント。「ご縁」として貯まる |
| 零（穴を塞ぐ） | 歩かない日が続くと町の色が抜けていく |
| チリン | 1日の始まりと終わりの通知音 |

「ポイントが貯まる」だけだった体験が、「今日も風をとおした」に変わる。これが**続く理由**になる。

## 3. 10体を「機能の担当者」にする

ここがこの企画の最大の強み。設定書の性格が、そのままアプリの役割になる。

| キャラ | 性格の核 | アプリでの役割 |
|---|---|---|
| **ポポ** | 行動派、失敗を笑いに変える | 主役。毎日のひとこと、達成の喜び |
| **モコ** | 「よかったことを一個メモ」 | 1日ひとつの「よかったことメモ」機能。歩いた日の日記 |
| **リン** | 速さ自慢、負けず嫌い | 友だちと歩数勝負。「せんべいおごり」 |
| **ピケ** | 小さな音を聞く耳 | 朝の散歩担当。早朝に歩くと出てくる |
| **ガロ** | 説教しない、一曲弾く | 歩数でBGMが解放される。旅立つ＝期間限定 |
| **ハカリ** | 全部数値化する | **週次レポート担当**。「計算上は」で始まる分析画面 |
| **ヨリ** | よりみち堂、せんべいで縁をつなぐ | **加盟店担当**。店に歩いて行くとせんべい（ボーナス） |
| **カナデ** | 毎話の始まりと終わりの「チリン」 | 朝と夜の通知。アプリの開始音と終了音 |
| **ソウ** | 感情を聞く | 今日の気分を1タップで記録。色で返す |
| **零** | 穴を塞ぐ、彩度が抜ける | 離脱の物語的表現。歩かないと町が灰色になり、歩くと色が戻る |

10体を一気に出さない。**ポポから始めて、歩いた分だけ住人が増える**。「あと何歩でリンに会える」が次の一歩の理由になる。

## 4. 1日の体験設計

**朝**
カナデの通知「チリン、はじまりの音♪」。開くとポポの今日のひとこと（日替わり）。ピケがいる日は早朝限定。

**日中**
何もしない。スマホが勝手に歩数を数える（Androidアプリ化が前提）。

**夕方**
カナデの「おしまいの音」。今日の風がとおったか。
達成なら**エピソードが1本開く**（30〜40秒の縦型絵本。すでに第1話の素材がある）。
モコが「今日のよかったこと、ひとつ」と聞いてくる。

**週末**
ハカリの週次レポート。「計算上は、先週比112%と算出します。……計算上は、ですが」。

**街で**
ヨリのよりみち堂＝pointpay 加盟店。歩いて店の近くに行くと「焼きたて一枚」。これが**加盟店への送客**になる。

## 5. pointpay 事業との接続

- **ポイントの位置づけ**：主役は物語とキャラ。ポイントは「ご縁」として小額に貯まり、加盟店で使う。歩数報酬の現金相当価値を大きくしない。
- **理由**：歩数に対する金銭的報酬は景品表示法・資金決済法の論点になる。案件メモにも弁護士確認の記録がある。**「歩いたから払う」ではなく「店に来たから店が渡す」**の構造にすると、送客の対価として整理しやすい。
- **加盟店側の価値**：ヨリの店として物語に登場する。来店で「せんべい」を渡せる。これは pointpay の「お店の招きネコ」というポポの設定そのもの。
- **測る指標**：継続率（7日・30日）、エピソード視聴完了率、加盟店への来店数、SNSシェア率（＝ニャンフルエンサー指標）。

## 6. 正直な懸念

1. **コンテンツ供給が命**。物語解放型は、エピソードが止まった瞬間に離脱する。週1本なら年50本。制作ラインはあるが、体制として組む必要がある。
2. **自動歩数はネイティブアプリ必須**。Webのままでは成立しない。Android から始め、iOS は費用と体制を見て判断。
3. **ポイントの法務**。上記のとおり設計で回避できるが、必ず弁護士に一度見せる。
4. **10体を出し切る誘惑**。全員出すと薄まる。最初の3ヶ月はポポ・モコ・カナデの3体で十分。
5. **ぱんちゃんとの切り離し**は済んでいる。ブランドは pointpay の赤・白・黒で一貫させる。

## 7. 段階案

| 段階 | 期間の目安 | 中身 |
|---|---|---|
| **0. 土台** | 〜1ヶ月 | Android アプリ化（自動歩数）。ポポの日替わりセリフ20種。連続達成。カナデの朝夕通知 |
| **1. 物語** | 2〜3ヶ月 | 達成でエピソード解放（第1話〜）。モコのメモ。ハカリの週次レポート。零の「色が抜ける」演出 |
| **2. 町** | 4〜6ヶ月 | ヨリ＝加盟店連携。pointpay ポイント交換。リンの勝負。iOS |
| **3. 拡張** | 半年〜 | 残りの住人。季節イベント（ガロの旅立ち）。ニャンフルエンサー施策（シェアで風が増える） |

段階0は、いま話している「アプリ化」そのもの。**企画としての判断は、段階0を「歩数計」ではなく「物語の土台」として作ること**。具体的には、最初から「風」「とおる」「チリン」という言葉と音で作る。

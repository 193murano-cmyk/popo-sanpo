# Android版（箱）のしくみと入れ方

## しくみ
- `android/` にあるのは「箱」だけ。中身は GitHub Pages の Web版をそのまま表示する。
- 箱がやることは2つ。Web版を全画面で表示する／スマホ本体の歩数センサーの値を Web に渡す。
- だから、見た目やセリフの修正は Web側（`index.html` / `css` / `js`）を直すだけで、アプリを入れ直さなくても反映される。
- 表示する URL は `android/app/src/main/res/values/strings.xml` の `app_url`。

## 歩数の取り方
- Android には「電源が入ってから今までの累計歩数」を数え続けるセンサーがある（アプリを開いていなくても数えている）。
- アプリを開くたびにその値をもらい、前回との差分を「きょうの風」に足す（`js/app.js` の `nativeSync`）。
- 初回はその時点を基準にするので、入れる前の歩数は入らない。
- 再起動でセンサーの値が戻ったときは、起動後の分だけ足す。
- 日をまたいで開かなかった分は、開いた日に入る（v0.2 の割り切り）。

## APK の作り方（自動）
- `android/` を変えて push すると GitHub Actions が APK を作り、Releases の「android-latest」に置く。
- 手で動かすときは Actions → 「Android APK」→ Run workflow。

## スマホへの入れ方
1. GitHub の Releases から `popo-sanpo.apk` をダウンロード。
2. 開くと「提供元不明のアプリ」の許可を聞かれるので、Chrome（またはファイルアプリ）に許可。
3. インストール後に起動。「身体活動」の許可を聞かれたら「許可」。
4. 歩いてから開き直すと、歩いた分が「きょうの風」に入る。
